FAQ

Yang sering ditanyakan.

Apakah BelajarKuy! menyimpan data di server?

Tidak. Aplikasi ini menyimpan progres secara lokal di browser menggunakan localStorage, tanpa akun atau server.

Bagaimana jika saya menghapus data browser?

Data BelajarKuy! dapat ikut terhapus. Gunakan fitur ekspor/impor JSON bila tersedia untuk membuat salinan.

Apakah kontak placeholder ini aktif?

Tidak. Email, nomor WhatsApp, dan alamat ditampilkan sebagai placeholder yang perlu diganti oleh pemilik proyek.
