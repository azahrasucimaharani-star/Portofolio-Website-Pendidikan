# KELASIA

Website statis multi-halaman untuk portofolio PT, dibuat sesuai PRD KELASIA v2.0. Teknologi yang digunakan hanya HTML5, CSS3, dan Vanilla JavaScript.

## Menjalankan

Buka `index.html` langsung di browser, atau gunakan static server lokal. Tidak ada build step, backend, database, login, pembayaran, maupun LMS.

## Struktur

- 7 halaman utama dan 2 halaman detail berbasis query `id`
- `assets/css/` berisi token, komponen, dan breakpoint responsif
- `assets/js/data/` berisi data demo kelas, program, dan mentor
- `assets/js/` berisi shell global, katalog, serta detail kelas

## Catatan data demo

Seluruh nama, foto, kelas, mentor, durasi, harga/status, institusi, dan copy pada situs ini bersifat fiktif untuk kebutuhan portofolio. Pendaftaran tidak dibuka dan tidak ada kanal pembayaran atau akun sosial yang diklaim nyata.

# Bimbelku

Website statis bimbingan belajar untuk siswa SD, SMP, SMA/SMK, dan peserta UTBK. Dibangun dengan HTML, CSS, dan Vanilla JavaScript tanpa backend.

## Menjalankan lokal

```bash
py -m http.server 8000
```

Buka `http://localhost:8000`.

## Deploy ke Vercel

Import folder atau repository ke Vercel, pilih **Other** sebagai framework preset, kosongkan build command, dan gunakan `.` sebagai output directory.

## Catatan produksi

Sebelum publikasi, ganti nomor kontak, alamat, kebijakan, harga, jadwal, foto, profil tutor, dan testimoni dengan informasi resmi. CTA pendaftaran belum aktif karena belum tersedia nomor WhatsApp resmi yang terverifikasi.
